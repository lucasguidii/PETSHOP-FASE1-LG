# PetShop Amigo Fiel - Fase 1

Projeto acadêmico da disciplina **Fundamentos de Sistemas Web**, do curso de Análise e Desenvolvimento de Sistemas - PUCRS Online.

## Objetivo

Construir a primeira versão estática de uma plataforma web para um petshop utilizando somente HTML, aplicando os conteúdos introdutórios de estruturação e navegação de páginas web.

## Funcionalidades

- Navegação entre as páginas Início, Produtos, Serviços e Ajuda.
- Visualização de 2 produtos da categoria Acessórios.
- Visualização de 2 produtos da categoria Rações não perecíveis.
- Visualização de 2 produtos da categoria Higiene e limpeza.
- Cada produto possui imagem, descrição e valor.
- Visualização dos serviços de banho e de banho e tosa.
- Serviços apresentados com descrição, valor e informação sobre tele-busca.
- Cabeçalho, corpo e rodapé nas páginas.

## Tecnologias utilizadas

- HTML5
- Sem CSS
- Sem Bootstrap
- Sem JavaScript

## Arquivos principais

- `index.html`: página inicial.
- `produtos.html`: catálogo com as três categorias de produtos.
- `servicos.html`: serviços de banho e tosa, com e sem tele-busca.
- `ajuda.html`: ajuda e descrição das funcionalidades.
- `assets/`: imagens usadas no catálogo.

## Como executar

Abra o arquivo `index.html` em um navegador ou acesse o endereço publicado no GitHub Pages.
